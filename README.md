# CampusConnect+

A student-focused platform for peer learning, mentorship, opportunities, and academic resource sharing.

## 🎯 Problem

Students often struggle to find reliable academic guidance, senior mentorship, hackathons, internships, and affordable academic resources. Information is scattered across different platforms, making it difficult to find the right help at the right time.

## 💡 Solution

CampusConnect+ brings these services together in one platform. Students can ask questions anonymously, connect with seniors, discover opportunities, join academic communities, and exchange useful educational resources.

## ✨ Features

- Anonymous Q&A
- Senior mentorship
- Academic communities
- Hackathon and internship opportunities
- Academic resource exchange
- Upvotes and reporting
- AI-powered discussion summarization
